# 《牧师寓所谋杀案》游戏改编草案

状态：2026-10-28起采用1930年英文小说为唯一剧情依据，替代此前回忆级结构参考。本文包含结局；是制作文档；已接入的调查范围见文末分阶段记录，不整体发给玩家或 NPC。不混用 BBC、ITV 改编。

来源采用 Wikisource 原著章节，按下文逐项链接。中文姓名只是阅读标签，稳定标识采用英文；文中 E、C、F 是本文局部引用编号，不是新增源码类型。只摘要案情，不复制原著对白。

## 1. 本次改编的方式

首版采用**警方初查阶段的现场调查**。玩家作为协助调查者进入书房，检查物体、询问人物、出示证据并申请检查。玩家身份是游戏补充；保留原著的既定命案及人物关系，不将玩法改为阅读一份已经结案的答案。

开局定位为**周五上午，雷丁前夜已自首、安妮尚未作出本局认罪陈述的调查节点**。这是相对阶段，不另编一个原著没有给出的精确分钟。E01—E13已发生；E14中本局开局前已经完成的消息传播单独列入公开背景，尚未进行的正式问询由玩家参与。E15及后续情节不是开局历史。

| 时钟／范围 | 约定 |
|---|---|
| 既定历史 | 开局前发生的命案、现场处理、发现、警方封锁和雷丁自首不能被对话改写 |
| 游戏现在 | 周五上午初查，后续按显式调查阶段推进；点击物体、聊天次数或现实等待不会自动令剧情跨日 |
| 证词时间 | 旧笔录保留作出时间；玩家当前询问形成新证词，NPC只知道截至当前阶段已实际获知的信息 |
| 当前现场 | 由警方允许进入的已初勘现场；检视前明确原物、已收取物证及现场记录的区别，不允许任意破坏物证 |
| 首个可玩范围 | 书房检查、询问牧师或玛丽、核对座钟与到达证词，保存并恢复调查进度 |
| 结案后 | 案卷复盘对照本局过程、已查明真相及未解决问题，不反向给开局人物补知识 |

线索来源包括3D物体观察、现场检查、当面问答、证词矛盾和报告。文件是其中一种载体，不把所有调查改成读笔录。人物不因玩家提出凶手姓名就认罪，也不因未到某章而无条件拒绝可以进行的调查。

## 2. 环境与公开背景

| 内容 | 本案设定／制作约束 |
|---|---|
| 时间与地点 | 原著时代的英国圣玛丽米德村；不加入手机、监控、电子门禁或现代网络证据 |
| 核心现场 | 克莱门特牧师的书房；桌面、座钟、纸张、书写用品、电话、靠窗盆栽及窗外花园关系需表现 |
| 场景关系 | 室内走廊与厨房、花园、后门、小路、画室；先用平面图和调查入口表达，不需要全部做3D |
| 天气 | 不沿用原创稿的暴雨；第5章写有傍晚阳光。未核对的温度、雨量不设为证据 |
| 声音与视线 | 某人没听见或没看见，不自动证明没有发生；视点、时间段与遮挡要写入证词范围 |
| 调查能力 | 依原著时代的检查与材料，不收集侦探装备；不要求精确模拟枪声、弹道或血滴 |

画面只展示已配置的可调查外观。枪械消声、远处响声及现场处理采用固定检查材料和示意，不制作可自由试验的装置。书房不是封闭密室；不能沿用现代稿的固定玻璃窗设定。

上表是**原著后续基线**，不是本局必定发生的未来。保留其因果作设计依据，不把小说结局预先当成玩家可以调阅的档案。

| 本局情况 | 处理规则 |
|---|---|
| 玩家仍在首个调查切片 | 剧情保持在周五初查；到阶段目标后给出“阶段完成”，不是全案结案，不自动跳到周日 |
| 准备进入下一阶段 | 后续版本必须先配置参与人、时间或阶段、前提、结果及知情变化；推进前检查当前会话，不要求玩家按固定顺序找到线索 |
| 提前取得有效证据或实施保护 | 先记录其实际效果，再检查是否阻断后续行为；不能为了复刻原著强行放走受控嫌疑人、继续栽赃或使被保护者受害 |
| 已阻断原著后续事件 | 相关事件不发生，相应证词和报告不生成；不能继续调用原著原有结果。后续分支需经作者预写和验证 |
| 提出有效介入但该分支尚未实现 | 保存证据与待处理调查／保护请求，在能力边界结束该演示阶段并说明后续未实现；不虚构已经执行，也不继续推进被它影响的事件 |
| 只有无依据猜测 | 不自动拘捕或授予事实；可继续询问、检查与申请核验 |

不在这里给危险行为编写可执行操作或剂量。阶段推进不是无条件播放小说，原著未发生的替代结果也不能由AI临场编写。首个Demo不实现后续全部阶段；扩展前须补齐阶段转换与提前介入的处理。

## 6. 需要纠正的旧认识

- 雷丁与安妮是共谋者；两次认罪中的虚假细节是策略，不能改写成两名无辜者真心替亲人顶罪。
- 书房里是座钟，不沿用原创稿的挂钟。发现读数18:22、纸面所写18:20、座钟平时快十五分钟，是三个不同字段，不相互覆盖。
- 时钟与纸张的疑点服务于多层误导，不能简单理解为凶手忘记校时。对其动机的结局解释见第30章。
- 原著不能称为“侦探到场后完全静态”“人人的秘密都与命案无关”，也不能把全部情节说成没有预先布置。
- 不引入温控、尸僵操纵、暴雨延误法医、艺术馆、林舟或现代远程视频。

### 核心手法的作者真相

按第30章的重建：雷丁预藏枪并伪装来电调走牧师；安妮取用预藏武器实施枪击。后来另行制造的声响误导了时间判断。雷丁再进入书房，取走武器、留下伪造纸张、带走死者原信并改动座钟。两人的认罪制造“互相保护”的印象。这里保留结果与角色分工，不复现装置制作步骤。

这一段是结局解释层，不能直接作为玩家已取得的物证。第30章本身承认解释尚缺证明；后续证实依据为第31—32章的警方行动。原著对机械细节保留推测措辞，游戏也不升级为经过实验验证的唯一构造。[原文依据](https://en.wikisource.org/wiki/The_Murder_at_the_Vicarage/Chapter_30)

## 7. 证据、途径与推理限制

以下是游戏调查入口设计，入口名称和披露顺序是项目补充；具体材料仍从所列原著章节提取。陈述为假的内容依然可作为线索，但不能直接进入已确认事实。

| 线索 | 可获得的内容／来源 | 调查入口 | 不能直接推出 |
|---|---|---|---|
| C01 现场初始记录 | 尸体、未发现枪、座钟读数及桌上纸张；第5章 | 书桌与现场记录 | 读数就是死亡时间 |
| C02 座钟习惯 | 平时快十五分钟；第5—6章 | 询问牧师、格丽泽尔达并核对记录 | 减十五分钟就得到正确死亡时间 |
| C03 调离电话 | 召唤与病家实际情况冲突；第5章 | 询问牧师及核实病家情况 | 牧师能直接辨认幕后安排者 |
| C04 雷丁首份口供 | 前夜自首笔录与本局正式询问分别记录；约18:45的具体说法在获得后才披露；第7—8章 | 当面询问及警方已有笔录 | 供述、凶器持有与实际开枪是同一事实 |

| C06 邻居观察 | 路线、短暂离开视线、画室前后及声响；第9章 | 询问邻居，结合现场视线图；需要时留存证词 | 没看到携枪等于不可能接触凶器 |
| C07 独立行踪核查 | 两人分开后的活动；第11章 | 斯通、哈特内尔等证词 | 证明某段不在场就覆盖全天 |
| C08 医学材料 | 初查估计、子弹检查及验尸庭意见；第5、7、18章 | 分阶段检查档案 | 用现代医学常识重新算出原著没有给出的秒数 |
| C09 后续改口证词 | 雷丁给出的“发现尸体、带走枪、保护安妮”解释；第12章 | 在本局实际改口后比较两版供述 | 把他宣称的担心记为真实误信 |
| C10 另一封信与霍斯事件 | 信的内容、发现位置、救治及解释；第28—30章 | 后续阶段在本局实际发现、检查与救治后取得 | 财务过错等于杀人，或危险状态等于自杀认罪 |
| C11 警方最终记录 | 设局后的跟踪与交谈取证；第31—32章 | 提出取证计划，由后续已实现阶段执行后取得结果 | 马普尔先提出理论就等于已有直接证据 |

## 人物对话资料补全草案（待审阅，尚未接入运行）

### 资料必须覆盖的内容

每位人物需提供：认识的人及称谓／关系；自身已发生经历的顺序；时间精度与记时依据；当时看到、听到和明确没有感知到的情况；主观解释；隐瞒与披露策略。角色已经提及的姓名必须能解释，简称和同一人物全名应关联。资料是可理解的经历，不是穷举玩家问法的标准答案。

自身经历在小说后续章节才被问出，不等于角色此前不知道。开局前已经历的事情可在玩家有效追问时披露；尚未发生的报告、认罪或获知事件不能倒填。答复不要求先匹配某条预写证词，授予关键材料仍由后端核定。

### 牧师资料草案

- 斯莱克：调查本案的警探，周四到现场；牧师已与其接触，对他粗鲁、不肯听解释的态度不满。问“这是谁”须直接说明身份，不能答不知道。（[第5章](https://en.wikisource.org/wiki/The_Murder_at_the_Vicarage/Chapter_5)）
- 梅尔切特：负责本案的警察局长；海多克是当地医生，玛丽是寓所女佣。身份与认识程度分别写明，不因玩家尚未取得该人的材料就抹掉日常认识。

### 玛丽资料草案

- 认识寓所住户、来往客人、医生与调查警方；个人认识程度按原文和已核定背景补齐，不能因没有线索ID就一概不认识。

- 她没有意识到屋内发生枪杀，但回想时记得一声以为来自树林的奇怪响声。说不准精确时刻，只能回忆在茶点后、雷丁到来前约十至十五分钟；不能答“不知道自己听没听到”，也不能改成“什么声音都没听到”。听见声音不等于认识其真实来源。（[第10章](https://en.wikisource.org/wiki/The_Murder_at_the_Vicarage/Chapter_10)）

### 加入提示词的规则草案

你应能解释人物资料中自己认识、提到的人名，说明其身份和与你的关系；不要因为他不是当前线索主题就回答不认识。回答自身行踪时，按本人经历作答，并区分计划、实际发生与别人的转述。

问你有没有听到或看到某事，应回答已记录的感知事实，并区分感知与理解。“听到响声，但以为在树林”既不是“没有听到”，也不是“知道谁开枪”。明确没有听到时直接说没有听到；只在时间、来源等具体细节记不清时限定该细节。

作者须在关键时段明确写出已感知／未感知及其范围。不要让模型把资料遗漏自动改成案件中的否定事实，也不要用一句“我不知道”替代已经提供的自身经历。后续补全资料可用明确的普通生活安排，涉及证据、行踪、目击与异响须核对原著，不凭日常常识添加。
