## 1. 作品与版本

- 原作：阿加莎·克里斯蒂（Agatha Christie），*The Murder at the Vicarage*，1930 年出版。
- 地位：**马普尔小姐（Miss Marple）系列的第一部长篇**，也是她首次在长篇中作为侦探出现。
- 叙事视角：第一人称，叙述者为**牧师**本人。
- 改编版本差异较大，选定前须注意：
  - 1986 年 BBC《Miss Marple》电视电影（Joan Hickson 主演）——一般认为最贴近原作。
  - 2004 年 ITV《Marple》（Geraldine McEwan 主演）——**对人物与部分情节做了改动**，不可与原文混用。
  - 2004 年之后的多版电视剧还有进一步改编。
- **本文以下的信度标注只针对"回忆级"结构认知，不代表任何特定改编版本。**

## 2. 结构骨架（本文的核心价值）

这是本作值得本项目参考的五件事，按对后端类型的价值排序：

1. **单一尸体、单一现场。** 命案发生在一间**书房**里，全案没有第二起死亡。侦探到场后世界不再变化——完全静态。
2. **死者是"惹人厌的人"，而不是"秘密最多的人"。** 死者是当地治安法官，因为刻薄、爱威胁人，**几乎每个人都恨他**。秘密分散在**活着的人**身上——这与《月光奏鸣曲》正好相反。
3. **每个嫌疑人隐瞒的是一件与命案无关的私事。** 婚外情、财务问题、身份冒充、旧丑闻——各不相同、互不相关。这是本案最重要的结构特征：某个嫌疑人说谎，**不代表他是凶手**。
4. **多人先后"自认"开枪。** 至少两个人先后承认自己是凶手，且都不是。这是本作最著名的装置，也是**审讯型玩法最理想的素材**：玩家的每一次"逼问成功"反而可能把自己推向错误结论。
5. **解法依赖时间矛盾 + 物证的交叉，而不是机关运作。** 关键在于核清"谁在什么时刻在哪里"，并用物证拆掉伪证——不需要模拟任何机械装置。

以上五点与你 `plan.md` 5.1 的"暴雨夜封闭书房"是同一套骨架，道具清单也基本重合（时钟、酒杯、文件、抽屉、壁炉、脚印、挂画、门锁）。

## 4. 时间线（相对时间，不含精确时刻）

本文不编造分钟级时间。改编时必须由作者明确选定每个节点，并按 `case_truth_types.md` 第 3 节的规则分开记录三条时间线。

| 相对阶段 | 客观发生的事 | 备注 |
|---|---|---|
| 案发前数周至数月 | 村里的多桩私事各自积累：婚外情、财务困境、旧丑闻、被死者威胁的把柄 | 这些**与命案无关**，是红鲱鱼的来源 |
| 案发当日傍晚 | 死者与至少一名当事人发生冲突，并声称要去牧师寓所 | 具体冲突对象待核实 |
| 案发当日傍晚至夜间 | 命案发生，尸体在**书房**被发现 | **死亡时间的真实值待核实**；现场时钟的状态是本案关键物证之一（**中**信度） |
| 发现后至深夜 | 牧师、警方、村医到场；多名村民各自叙述当晚行踪 | 叙述互相矛盾，且矛盾**不一定指向真凶** |
| 次日 | 多人先后向警方承认自己是凶手 | 结构装置，非真凶 |
| 收束 | 马普尔小姐指出某人日常行为的异常，所有人聚集在牧师寓所，真相揭晓 | 具体破绽内容待核实 |

**这张表的用途**是用来对照 `CaseTruth.events` 与各 `Person.initialAwareness` 的填充。任何一格不确定，就在改编时明确"由作者选定"并标注为项目补充，不要让程序猜。

## 6. 用于项目的改编边界与待办

### 6.1 明确不采用的部分

- 不采用原作的人物姓名与英式乡村背景。v1 使用 `plan.md` 5.1 已有的中文现代场景与道具清单。
- 不采用原作的多版本剧情细节（各改编版本互相矛盾，成本高于收益）。
- 不复制原作的具体诡计手法。

### 6.2 明确借鉴的部分

只用第 2 节的五点结构骨架，以及第 5.1 节的装置类型。

### 6.3 改编时必须完成的动作

1. 先完成第 5.2 节的 7 条核对——**如果目标是"直接改编原作"，这是硬前提**。
2. 如果目标是"只借结构、自己写案情"（**推荐**），则第 5.2 节改为**由作者自行设计**，并标注为项目补充；此时本文只保留第 2 节与第 3 节的"秘密分布方式"作为设计参照。
3. 无论走哪条路，都必须先产出以下三张表，才能转写为 `CasePackage`：
   - **事实—证据表**：每个结论 Fact 需要哪一组 Clue 才能推出（对应 `SolutionRequirement.acceptedClueSets`）
   - **证据—道具表**：每条线索出现在哪个 `Entity` / `InquiryPoint`，是走 `Fixed` 还是 `Semantic` 路线
   - **秘密—知情表**：每个 `Person` 的（真实行动 / 知晓范围 / 隐瞒内容 / 对外说法）四栏
4. "秘密—知情表"中，**任何一栏存在空白的角色都应删除或合并**——这是"每个人心怀鬼胎"的量化检查方式，不是气氛描述。
