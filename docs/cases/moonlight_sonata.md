# 固定案件参考：钢琴奏鸣曲《月光》杀人事件

> 包含凶手、手法和结局的完整剧透。本文为原作案件的概要资料，供课程项目建模参考，不是游戏中直接展示给玩家的简介，也不是已经确定的改编剧本。

## 1. 作品与版本

- 原作：《名侦探柯南》第 7 卷 File.2—7，对应总 File.62—67。
- 动画：1996 年版第 11 集特别篇；2021 年重制版第 1000—1001 集。部分平台拆分编号不同。
- 地点：月影岛。案件以钢琴、《月光》、乐谱暗号及十二年前的旧案相互串联。
- 本文记录各版本共同的主线；精确台词、分钟级时间和场景布局仍应在选定版本后复核。

作品范围及案件概述参见[小学馆《少年 Sunday》官方案件页](https://websunday.net/episode/11922/)；动画版本参见[柯南百科的版本对照](https://www.conanpedia.com/FILE62-67)。

## 3. 时间线

### 旧案与前因

| 相对时间 | 事件与事实层次 |
|---|---|
| 十二年前 | 麻生圭二及妻女死于住宅火灾；岛上传闻将其解释为麻生杀害家人后自杀，但这是需要推翻的表面说法。 |
| 旧案真相 | 麻生涉及的毒品交易及退出意图引发灭口；川岛、黑岩、西本、龟山是加害方。成实当时因住院逃过一劫。 |
| 两年前 | 成实以医生身份来到岛上；龟山得知其真实身份后心脏病发死亡，成实获知父亲死亡背后的秘密。 |
| 本案开始前 | 小五郎收到署名麻生圭二的委托及费用；实际委托者是成实。 |

开篇传闻见[读卖电视台前篇介绍](https://www.ytv.co.jp/conan/archive/k20210306.html)；旧案真相与龟山死因见[柯南百科背景事件整理](https://www.conanpedia.com/FILE62-67)。

### 岛上调查主线

| 阶段 | 玩家／调查者经历的事件 |
|---|---|
| 第一天白天 | 柯南一行上岛，得知委托署名者早已死亡，并接触村长选举相关人物。 |
| 第一天夜间 | 龟山法事期间，《月光》第一乐章响起，川岛的遗体在琴房被发现。 |
| 第二天白天 | 警方调查、询问相关人员；成实以医生身份参与死亡判断。 |
| 第二天傍晚 | 第二乐章通过广播响起，黑岩在广播室被发现遇害，现场留有血写乐谱。 |
| 第二天夜间 | 调查者追查旧乐谱；琴房发生可疑活动，村泽被袭击。 |
| 同夜后续 | 西本在仓库被发现缢死，现场留下试图将案件归咎于他的乐谱“遗书”。 |
| 真相揭晓 | 录音与死亡时间的矛盾、旧案资料及身份线索共同指向成实。 |
| 结局 | 成实在公民馆火灾中救出柯南，自己最终未能生还。 |

广播室发现与旧乐谱调查见[读卖电视台后篇介绍](https://www.ytv.co.jp/conan/archive/k20210313.html)；事件次序与结局见[英文案件资料](https://www.detectiveconanworld.com/wiki/Moonlight_Sonata_Murder_Case)。此表表示剧情阶段，不表示各起犯罪的精确实施时刻。

## 4. 核心真相与证据方向

| 事件 | 真相概要 | 调查重点 |
|---|---|---|
| 川岛遇害 | 成实将其溺死后搬至琴房，以录音营造钢琴演奏的表象 | 海水、沙土、搬运痕迹、录音设备；发现现场与死亡地点的区别 |
| 黑岩遇害 | 成实杀人后利用录音播放安排和错误的死亡时间判断制造不在场证明 | 磁带空白段、自动翻面、广播操作及现场照片；音乐响起并不等于刚刚死亡 |
| 西本遇害 | 成实杀害西本，伪装成畏罪自杀 | 缢死现场条件及暗号遗书的合理性；遗书内容不能直接视为事实 |
| 村泽受袭 | 平田为掩盖钢琴中的毒品交易而袭击他 | 钢琴暗格、可疑出入及相关痕迹；另案嫌疑不能直接证明连环杀人 |
| 成实身份 | 成实是旧案幸存的儿子 | 父亲遗留乐谱、姓名读法和家庭记录；身份关联须结合犯罪证据判断 |

手法和证据概要依据[英文案件资料的 Evidence / Conclusion 部分](https://www.detectiveconanworld.com/wiki/Moonlight_Sonata_Murder_Case)。具体录音时长、设备工作方式与逐人不在场证明，建模前仍需对照选定版本验证，不能仅靠概要补齐。

成实的主要动机是为家人复仇；委托侦探同时体现其希望被阻止的矛盾心理。父亲留下的乐谱也承载了与复仇不同的心愿，这构成结局的重要情感冲突。参见[柯南百科委托及结局整理](https://www.conanpedia.com/FILE62-67)。

## 5. 地点与可探索对象

原作的重要空间包括公民馆琴房、仓库、法事区域，以及村公所广播室；另有诊疗所、警务地点、海边和麻生旧宅相关背景。广播室的建筑归属与游戏地图应在确定采用的版本后统一，不宜自行假定所有地点都在同一栋楼。参见[柯南百科空间整理](https://www.conanpedia.com/FILE62-67)。

以下为游戏交互候选，属于建模建议，并非原作逐项交互流程：钢琴、琴凳、录音机、磁带、乐谱、窗户、通往海边的门、广播设备、现场照片、旧档案和钢琴暗格。

## 6. 用于项目时的边界与待办

以下均为实现建议，尚未确定改编范围：

- 完整原案涉及多起死亡和多个调查阶段，不能直接当成静态单房间案件；可以先实现第一案的探索取证，再逐步开放后续阶段。
- 分开记录真实事件时间、音乐播放时间、尸体发现时间和证人声称的时间。保留未知值或区间，不为方便程序而编造精确时刻。
- 对人物分别保存公开资料、私人知识、实际行为和证词；人物知道的事情不等于愿意说出的事情。
- 原作没有穷举每个人在每一分钟的位置，也没有提供完整 NPC 对话树。新增行动、对话、线索位置及解锁条件必须标注为项目补充。
- 当前资料是含真相的开发文档；后续玩家接口不能直接返回本文件或全部案件数据。
- 下一步应先选定参考版本，再制作“事实—证据—知情人物”表，核对证据链后转换为强类型案件数据。
