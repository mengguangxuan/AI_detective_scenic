## 2. 可以单独下发玩家的公开字段

**简介：**海伦·斯托纳担心自己正在经历与姐姐去世前相似的事情。你受托前往庄园，调查当年的疑点，并核实她如今面临的危险。

**目标：**检查现场，听取相关人物的实际经历，查明旧案并设法保护委托人。

**背景：**海伦的姐姐约两年前离世，近期维修使海伦搬进姐姐原来的卧室。

开局材料为海伦的经历记录与已核查的遗嘱摘要。它们是本次制作选择的初始合法材料，必须按条目投影，不能因玩家拿到材料就给其全部作者真相。人物简介只使用公开身份与关系；不得从私情或未来事件生成带答案的介绍。

## 5. 地点、物件与模型制作任务

JSON 登记8处地点：`grounds`、`corridor`、`middle_room`、`helen_old_room`、`roylott_room`、`inn`、`offsite`、`baker_street`。后两处是背景范围，不要求独立3D场景。

| 场景要求 | 模型必须保证的关系 | 验收方式 |

## 8. 玩家操作与分支边界

基准动作序列在 JSON 的 `baselineActionSequence` 中：取证并商量安排、到旅店观察、收信号后进入守候、听见声音后选择干预、实际进房确认现场、完成隔离、说明及报案。该序列是验收输入，不是自动替玩家执行的剧本。

动作需编译真实位置、移动耗时、灯与百叶窗状态、同伴是否同行及行动完成时刻。当前文档未生成这些底层配置；不能从“安静守候”四字猜测可执行效果。

| 独立变体 | 设置 | 预期 |
| --- | --- | --- |
| 犯罪计划前被控制 | 测试装置明确将罗伊洛特设为受控制 | 相应计划取消，依赖计划终止，不强制死亡；不授予玩家口头拘留能力 |
| 玩家错过信号 | 玩家不在观察位或未实际观察 | 信号可以发生，但玩家没有看见记录 |
| 华生不在场 | 声音或动作时华生在别处 | 不发其目击知识；缺席路径不能冒充原作双人在场事件 |
| 玩家未响应 | 未执行实际干预操作 | 不生成以干预为前提的回返、反噬、死亡；阶段未完成，不补写海伦死亡或自动成功 |
| 重试与重启 | 放蛇后保存、重启并用原请求重试 | 位置、知识、事件时刻及原回执一致，不重复触发 |

前三类干预／缺席安排是项目测试补充，不能归到原作。未响应后的完整未来尚未定义，不能借“阶段未完成”声称实现任意自由分支；将来若要开放该分支，需作者补写、审核并生成独立事件与结果。

## 9. 推理、结案与复盘字段

评审关注责任、经济动机、空间手法、观察边界与本局实际结果。JSON 为每项列出了可引用材料。五项是本样本的写作选择，不要求所有案件必须五组；本案数量不能延续成为引擎限制。

评审根据实际取得的证据和玩家解释判断，不能凭猜中凶手或勾完材料直接通过。物品描述不提前解释手法；人物自然表达而不是背审核标准。

本局没有发生的事件，不得作为已证事实或在复盘中写成实际结局。作者完整解答只在明确结案或主动查看后公开。原作结尾的后续官方调查仅作背景，不据此补出本系统尚未实现的警方过程。

## 10. 上传与审核的预期结果

### 10.1 正常输入

未来上传入口应保存本作者稿的未知值、来源、引用、私情和约束，按作者隔离。保存后原样读取，不能把作者字段裁成只有运行投影。它应作为可审核草稿进入流程，而不是直接进入公开案件目录。

审核至少应区分以下结果：

| 项目 | 预期报告 |
| --- | --- |
| 原作虚构机制 | 明确现实局限并保留本作者样本选择，不擅自改写 |
| 历史时间精度 | 报告现有精确时间类型不能无损承载，不要求编造时间 |
| 场景与资源 | 尚需模型制作并登记，不冒充已有书房／树林包可用 |
| 观察者条件 | 部分观察同时要求位置与实际观察操作，不能忽略后一个条件 |
| 动作与状态 | 需编译移动、灯光、同伴及容器效果，自然语言不是脚本 |
| 未覆盖分支 | 明确主路径与阶段边界，不宣称全分支可玩 |
| 引擎能力 | 没有调度与事务集成，不满足可玩发布条件 |

其中 `EventObservation` 目前只有 `Direct`／`AtPlace`，不能直接表达作者稿中的 `requiredOperations` 与 `activePerception`。完成过观察操作不表示此后一直看着窗口。实体容器内部位置、灯光状态及未知精度历史也需要后续类型／编译设计承接；不能无声丢字段。这份样本就是用来暴露这些缺口，不为了让它“通过”而删除约束。

### 10.2 负向输入

JSON 的 `uploadAcceptance.negativeMutations` 给出了独立修改位置与预期诊断：未知事件引用、违反因果的触发、开局人物知道未来死亡、把旧记忆当当前否定证据，以及公开简介泄露完整答案。每次在独立副本中只改一个问题，错误报告定位相应字段；不要污染正常样本。

### 10.3 发布及运行验收
