## 3. 最近完成：语义推进首批实现

案件26使用作者提示族`interviewPromptVersion=3`、当前人物模板10／答复协议5。旧25源与指南按字节归档，旧调查不自动升级；模板7—9开发期冻结请求也保留原分支。

自由问询分为人物发言、独立语义核对两次调用：

- 人物只接收自身知识、私情、策略、实际收到的材料和自身历史，输出`reply`与`focus`，不自行发证据。
- 核对器接收实际发言、本人原供、实际材料及作者允许登记的主张；不接收人物秘密或完整真相。识别逐项主张、逐字原文与依据材料ID。
- 程序检查合法主张、原文引用、已收到的依据、本人原供及事务权限，再保存实际原话。新供不覆盖旧供；收到材料、相信材料、改变说法分别处理。
- 固定备用与自由问询共用登记逻辑。固定备用仍有作者审核的答复和材料配方；不意味着任何问法都应获得同一句话或必定改口。
- 作者通过共同事实引用明确关联的同义材料可满足同一条件，出示历史保留真实ID；任意文本不会因标题相似自动归并。

有效人物答复先保存在原请求可选`draft`中。核对服务／整体格式失败时保留原请求，重试只核对已保存答复；个别非法登记丢弃并以`unconfirmed`提示，保留原话和合法项。两次模型等待均不占数据库连接，完成时复核序号与租约token。未新增数据库表，不清存档掩盖失败。另修复重试异步回执覆盖当前人物选择、导致问询区消失的问题。

## 4. 语义验收共识与未解决问题

用户指出现实人物反应不唯一，不能用“出示这组材料后必须撤供”验收。对话中已提出并解释以下标准，后续应据此设计测试：人物可以坚持、怀疑、反问或改口，需符合本人知识、保护意图及实际材料；系统应忠实登记实际发言，不登记未说出的内容。预设答复检查登记／权限／恢复应确定，真实模型试玩检查语义边界，允许多种合理反应。不要用强制台词消除人物差异。

当前仍不是通用的“撤回任何一句话”系统。登记的是作者预设主张：例如雷丁主撤供要求撤回独自开枪，并解释进屋见上校伏桌、拿走枪及为安妮承担。只说“认罪不是真的”可能尚不满足整项，不能把这类漏记全部归因于角色坚持。把“撤回旧供”和“提出完整替代解释”拆开，是可讨论的后续改进，尚未实施，本轮也未要求先做它。

语义是否等价、引用理由是否相关主要由核对模型判断。程序能检查引用／权限，不能独立证明语义正确。已知质量样本：

- 模板9曾误述枪属于上校，原记录保留；模板10独立来源追问正确回答本人所有，没有自动撤供。
- 牧师曾额外补充资料未提供的约见理由，未宣称已彻底解决正文补造。
- 同一调查首轮明确撤供但核对未给出合规登记；保留原话和`unconfirmed`。后续另问修正内容与实际依据，真实雷丁新供→安妮撤供／来访修订→警方区分新旧版本已登记。后续成功不等于旧失败重判成功，仍存在漏记波动。

这些列为已知限制，不把固定流程或类型检查通过写成任意自然语言均正确，也不默认因此继续无限微调首案而推迟上传。

## 7. 下一阶段建议顺序与验收

建议先做能端到端验证的小范围上传闭环，再扩展作者体验；下一上下文先核查源码并给出具体方案与估时，不依据本交接虚报工期。

1. **用一个独立小案件验证复用边界。** 新caseId、独立人物／事实／线索和真相，使用已登记表现模板；识别核心逻辑、固定节点和首案配置的耦合。不能仅换首案标题就宣称通用。抽离确实阻碍第二案的假设，保留旧版本路径。
2. **确定作者输入契约。** 首版建议结构化JSON文件，包含格式版本、公开介绍、真相、人物知识／策略、材料与取得路径、地点／表现绑定、可执行操作、语义主张条件及结案评审依据。完整旧首案JSON仅作参考，不要求用户手填八千行。字段精简／默认模板需明确会生成什么，不能无声丢弃输入。
3. **做校验和预览。** 返回字段路径、原因及可修正提示；硬错误不入正式目录。结构／引用／权限与能力检查、可达性／前置循环检查、时间因果及知识隔离的模型辅助审查分层报告。语义审查不能证明正确，结论需作者审阅和试玩，不能拿模型一句“通过”替代发布检查。
4. **接上传→保存草稿→检查报告→预览／试玩→发布→目录开局。** 上传时不立即覆盖发布内容；草稿只向作者开放。用户明示发布后才进入可见目录；发布内容冻结，修改生成新修订，旧调查和回执继续绑定旧版。需要什么草稿存储、状态和权限，按该流程设计，尚无实现。
5. **同步作者示例、指南与回归。** 新案完整取证、问询、推理和结案跑通，再验证两个案件隔离、发布重试、冲突拒绝及真实重启恢复；旧首案仍能继续。

首版建议限定现有登记模板与数据，不执行上传者脚本，不接受任意服务器文件路径，不让NPC获取作者完整真相。文档／文本导入并由模型生成草稿、可视化编辑、复杂资源包、自定义3D和完整账户发布平台可后续分批，属于建议范围而非已获用户确认的裁剪。

最低验收证据应包含：一个不同真相的第二小案从文件上传到可玩目录；错误引用／未知能力被准确拒绝；公开接口不泄露答案／人物私情／别的作者草稿；模型输出不能越权发布或执行代码；不同案件及版本的调查隔离；重复提交不重复发布；更新内容不会覆盖原发布修订；新旧调查真实重启后能恢复。角色反应允许差异，材料登记和权限必须忠于实际发生内容。
