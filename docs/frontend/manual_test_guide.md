已有调查若是修订12或更早，刷新会保留旧内容，不能直接增加本次复验。页面显示“若要体验窗边视线复验……”时，确实要测新内容才另建修订13调查；旧存档仍保留。不要清理数据库或浏览器身份。

自由问询可测试：办理中向警方问“窗边视线复验进展如何？”，完成后问“复验时怎么安排观察，结果是什么？”。再向安妮或马普尔勾选“窗边视线复验记录”，分别问她们怎样回应；不要仅凭聊天文字判断材料是否入账，仍在线索整理确认。

报告描述的是警方本次选定站位与朝向下的观察，不能扩张为所有位置、房间全貌或任何人的无罪结论。复验由警方人员分任观察者与桌前在场者，不自动给普通人物增加本局参与复验的经历。当前3D场景是示意表现，没有窗外站位实测玩法，报告不是由自由镜头或运行时射线计算生成。

自由问询与固定追问的语义等价性问题仍按要求暂缓。需要确定性完成前置时，先使用本文固定按钮路线；这不代表自然语言阶段识别问题已经修复。

## 纸张原件检查的独立短路线（回归用）

**单独测试纸张时，不用重做安妮、雷丁或阿彻调查。** 旧修订11调查可以继续原流程，但没有新纸张核查；页面显示旧修订提示时，确实要测试本次新功能才另建调查。不要清理浏览器或数据库。新建当前修订后按下表操作即可。

| 顺序 | 去哪里 | 操作 | 预期 |
|---|---|---|---|
| P1 | [现场探索](http://127.0.0.1:5173/scene) | 展开“物品列表（备用入口）”，点击“纸张原位置”；也可直接点场景中的对应物品 | 显示原件由警方保管的“纸张摘录”。关闭弹窗即可，原件并不在现场 |
| P2 | [警方交流](http://127.0.0.1:5173/police) → 核查进展 | 点“申请检查纸张原件” | “纸张原件初检”显示受理、预计完成时刻；“申请比对纸张笔迹”仍不可用 |
| P3 | 页面上方案件时钟 | 点两次“整理并等待5分钟”，或继续其他调查直到预计完成时刻 | 初检显示“已完成”；线索整理新增“纸张原件：墨色观察”“纸张原件：指纹检查” |
| P4 | 警方交流 → 核查进展 | 点“申请比对纸张笔迹” | “纸张笔迹比对”显示办理中，尚未取得比对意见 |
| P5 | 案件时钟 | 点“整理并等待15分钟”，再点“整理并等待5分钟” | 比对显示“已完成”；新增“纸张笔迹比对意见” |
| P6 | 警方交流 → 展开“固定问答与材料登记（备用）” | 点“出示纸张摘录与检查结果，登记原件核查” | 新增“警方登记的纸张核查材料”，警方已出示清单包含摘录及三份检查材料 |
| P7 | [线索整理](http://127.0.0.1:5173/clues) | 查看材料并刷新 | 原“纸张摘录”、三份检查材料及警方登记共五份材料并存；案件时间、记录数和内容恢复 |

已经有部分进度时，直接从对应行继续：有摘录从P2起；初检完成从P4起；有笔迹意见从P6起；已登记则做P7和第5节的保存恢复检查。已经受理的项目不重复申请。案件中的10／20分钟不需要现实等待，切页和刷新也不会推进案件时间。

如需测警方自然问询，可以在办理中问“纸张原件检查进展如何？”“纸张笔迹比对进展如何？”，应按实际受理进度回答；完成后问“墨色检查结果是什么？”“纸张笔迹比对结果是什么？”，应使用已经完成的报告。其他人物不会自动知道报告，需要向本人实际出示。

纸张检查采用申请按钮执行。关于“自由问询已表达同样意思，但未计入关键追问”的问题已经记录为暂缓待办，尚未解决；需要明确验证材料登记时先用P6的固定入口。不要把这条测试路径理解为两种问询入口已经语义等价。

下面第1—6节保留阿彻调查及原问询流程，供回归旧功能和定位已有进度；它们不是纸张检查的前置；窗边复验需要的准备步骤已在顶部单独列明。

## 1. 阿彻调查回归：先判断从哪里继续

打开 [警方交流](http://127.0.0.1:5173/police)。启动和模型配置问题见[验收准备](acceptance_preparation.md#1-先检查是否已经启动)。

**同一修订中的调查会自动保存，关闭网页、刷新或重启后端后，不必从头玩。** 先去[线索整理](http://127.0.0.1:5173/clues)查看已有材料，再按下表选择起点；已取得的材料不用重复领取。

| 现在的情况 | 从哪里继续 |
|---|---|
| 已有“警方登记的住处核查材料” | 直接做第5节的刷新恢复、自然问询检查；主流程已完成 |
| 已有阿彻太太的两份材料 | 第4节步骤4，向警方登记 |

网页当前没有直接展示案件修订号，也没有选关、检查点载入或一键补齐前置的按钮。新剧情以新修订发布，旧调查保留原内容，不能靠刷新升级。只有确实需要换修订或从零测试时才点“新建调查”。原调查虽保存在服务器，当前网页没有历史调查列表；切换前若还要保留便于继续操作的旧调查，不要随手新建。

阿彻调查**不要求先完成书房的时间核对，也不要求先操作3D物品**。为了测试阿彻调查，可以直接走下面的问询与警方路线。

## 2. 操作方式：先用固定入口准备，再测自由问询

准备前置时优先点固定入口，路径明确，也不需要调用模型。要测试模型时，再在已开放的人物页使用自由问询。

- **人物的固定问题**：打开[人物问询](http://127.0.0.1:5173/interviews)，在上方选择“与某人交谈”，展开下方“固定问答与材料笔记（备用）”，点击对应问题。每次换人后，核对区域标题仍是要询问的人。
- **警方的固定问题／材料登记**：打开[警方交流](http://127.0.0.1:5173/police)，展开“固定问答与材料登记（备用）”，在“向警方了解情况”区域找对应按钮。
- **联系与申请核查**：在警方页上方的“调查安排”“核查进展”区域操作，不在备用折叠区里。
- **补充问询的关键追问**：选择雷丁或安妮后，使用主面板“补充问询准备”中的按钮；这些按钮不在下方备用区。可展开“查看准备条件”找缺项。
- **判断是否取得材料**：以[线索整理](http://127.0.0.1:5173/clues)里的材料为准。已经成功取得的固定问题通常会消失，正文仍在笔记中，不代表丢失。

仅在聊天框中说“安排会面”“帮我核查”不会替代联系／申请按钮；仅有一段自然答复也未必取得了材料。只有实际记录的材料和关键回应才能满足后续条件。

已经有进度时，按每段的“完成标志”跳过做完的部分。下面列出阿彻调查所需的前置；其他现场检查、闲聊和支线对照可稍后体验。

### C. 雷丁的补充问询

先到警方页检查两项核查都已完成，应有“医生到场与初查时间记录”和“手枪与弹头核验结果”。如仍在办理，点页面上方“整理并等待5分钟”，直到完成。这里推进的是案件时间，切页、刷新和现实等待不会推进。

回人物问询，选择雷丁：

| 顺序 | 所在区域 | 点什么 | 完成后应看到 |
|---|---|---|---|
| C1 | 主面板“补充问询准备” | “出示行踪与检查材料，追问六点三刻的说法” | 记录雷丁对行踪与医学材料的回应，相应准备条件完成 |
| C2 | 同一区域 | “出示安妮在本局的认罪陈述” | 记录雷丁对安妮陈述的回应；准备条件全部完成 |
| C3 | 同一区域 | “开始雷丁的补充问询” | 显示“补充问询已开始”，但还没自动取得补供 |
| C4 | 下方固定备用区 | “记录补充供述：你在书房看见了什么？” | “雷丁的补充供述” |
| C5 | 同一区域 | “追问补充：枪平时放在哪里？” | “雷丁补充：枪的存放与接触” |

**完成标志**：雷丁的首份供述、补充供述同时保留，另有枪支存放的补充材料。如果早先已开始补充问询，直接补C4／C5即可，不要再找已经消失的C1／C2按钮。

### D. 安妮的补充问询与警方登记

人物问询中选择安妮：

| 顺序 | 所在区域 | 点什么 | 完成后应看到 |
|---|---|---|---|
| D1 | 主面板“补充问询准备” | “出示男仆证言与核验，追问枪的来源” | 对应准备条件完成 |
| D2 | 同一区域 | “出示雷丁补充供述与行踪，追问当晚经过” | 对应准备条件完成 |
| D3 | 同一区域 | “开始安妮的补充问询” | 显示“补充问询已开始” |

D5会一起登记实际向警方出示的四份供述，不必先逐个勾选再点一次“向警方出示”。想测试自然交流时，可以改为在警方自由问询区勾选四份材料并提问。

**完成标志**：警方页“调查安排”出现“联系阿彻太太，核实雷丁住处的情况”。至此进入阿彻调查。

## 4. 阿彻太太调查回归

1. 在警方页点击“联系阿彻太太，核实雷丁住处的情况”。“已联系的核查对象”应出现她。此时到线索整理检查：尚未询问就不应自动得到她的两份材料。
2. 前往人物问询，点击“与阿彻太太交谈”。在固定备用区点“询问：最后一次记得看见枪是什么时候？”，应取得“阿彻太太的见枪回忆”。也可以在自由问询区问“最后一次看见枪是什么时候？”。
3. 点“询问：你怎样照料住处，能说明谁来过吗？”，应取得“阿彻太太的照料范围”。也可以自由问“你每天怎么照料住处？能说明谁来过吗？”。两份材料都需要实际取得。
4. 回警方页，在固定备用区点“出示雷丁与阿彻太太材料，登记住处核查”。应取得“警方登记的住处核查材料”。这会一并向警方出示“雷丁补充：枪的存放与接触”及阿彻太太的两份材料。
5. 在线索整理确认三份新材料存在：阿彻太太的见枪回忆、阿彻太太的照料范围、警方登记的住处核查材料。雷丁、安妮的首供与补供也应保留。

如果要单独测试警方的模型交流，第4步可改为：在警方的自由问询区勾选上述三份待出示材料，问“请登记阿彻太太与雷丁关于枪的材料，接下来还需要核实什么？”。以实际获得“警方登记的住处核查材料”为完成标志。

本轮验收关注：联系是否明确执行、证词是否需要实际询问、警方是否只使用实际收到的材料，以及记录能否恢复。阿彻太太的回忆不能直接变成已完成搜查、确定取枪者或排除某人的结论。

## 5. 不重开调查也能重复检查的内容

完成第4节后，保留当前调查即可继续测：

| 检查项 | 操作 | 预期 |
|---|---|---|
| 刷新恢复 | 记下页面顶部材料数、调查记录数和案件时刻，刷新页面 | 三者不变；证言和警方已出示材料仍在 |
| 跨页共享 | 在线索整理、人物问询、警方交流之间切换 | 使用同一调查，已取得材料一致 |
| 已有人物自然回答 | 再选阿彻太太，发送一个新的问题 | 可继续问询，不必重新联系；新问询会新增记录并推进案件时间 |
| 对话恢复 | 刷新后重新选择阿彻太太 | 已保存的自由问询仍在；固定回答在材料笔记里，不要求伪装成自由对话 |
| 后端重启恢复 | 按验收准备中的步骤优雅停止、启动后端，再刷新 | 联系状态、材料、警方登记和原先记录恢复 |
| 首供／补供保留 | 去线索整理查看“供述版本对照” | 已取得的首供与补供并存；未询问的补充项可以仍显示未取得 |

只有要重测“一次性联系前”“尚未得到证言前”“尚未向警方出示前”等状态，才需要另开一局。同一局中不能靠刷新撤回已经发生的调查。

若要额外看完整供述对照，可以补问雷丁“你动过钟、纸张或尸体吗？”，安妮“你从花园到画室的经过？”“你接触过雷丁的枪吗？”。它们不是进入阿彻调查的必做前置。

## 6. 卡住时按这里排查

| 现象 | 先检查什么 |
|---|---|
| 找不到安妮／男仆／斯通／哈特内尔 | 是否在警方页执行对应联系按钮；只聊天提出建议不算安排 |
| 找不到阿彻太太的联系按钮 | 是否旧修订；是否已取得“警方收到的首供与补充供述”以及“雷丁补充：枪的存放与接触” |
| 找不到某个固定问题 | 核对当前选中人物；展开备用区；再去线索整理检查材料是否已经取得 |
| 没有行踪／医学的关键追问按钮 | 检查B段材料及两项核查结果；已开始补充问询后，旧追问按钮会退出当前阶段 |
| “开始补充问询”不可点 | 展开“查看准备条件”；必须实际向本人出示材料并完成两次关键追问，仅拥有材料不够。用C1／C2或D1／D2补齐 |
| 核查一直在办理 | 确认确实点击了申请按钮，再推进案件时间到预计完成时刻；现实等待无效 |
| 模型说了相关内容，但后续入口没出现 | 在线索整理确认目标材料是否入账；如没有，可走对应固定入口；保留这次问题和答复供反馈 |
| 模型未配置、响应失败或回复未通过检查 | 当前问题会保存；用固定入口继续准备，不必因此重新开局 |
| 联系或问询后网络中断，结果不确定 | 点击“用原请求重试”；不要重新创建调查来解决 |
| 提示操作已保存但视图没更新 | 点“重新读取视图”；不用重新执行同一次操作 |

反馈问题时，写明所在页面、选择的人物、点击的按钮或输入的问题、预期与实际结果；最好附页面上的案件时刻及材料名称。不要为排障清理数据库、浏览器身份或原请求。

## 7. 后续维护约定

每次交付需要手动体验的新功能时，同步维护本文件：

1. 更新顶部当前修订和“本次测试重点”，让用户先看到本次要测什么。
2. 按实际页面文案写前置、操作和完成标志；已有进度能跳过的部分要说明，不能只写“按之前流程完成”。
3. 提供一条可照点的固定入口路线，再提供必要的自然语言测试问题；标出可选步骤。
4. 核对新旧修订、保存恢复与实际可用入口，不把自动化测试内部造状态当成网页现有功能。
5. 本文保留当前可执行指南；历史验证结果写入实现／交接文档。启动、密钥配置等环境步骤继续由[验收准备](acceptance_preparation.md)维护。
