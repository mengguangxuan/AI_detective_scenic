## 本轮先测：实际说法的语义登记

**从案件详情新建修订26。** 旧25及更早调查不迁移，原规则与原请求回执保留；旧25操作见[归档指南](manual_test_guide_v25.md)。场景仍为study/6，传唤规则沿用开局自由联系。

1. 在人物问询选牧师，用自己的话问 `那座钟平时是不是走得不准？你有什么拨钟习惯？`。明确答出快十五分钟后，核对答复下方“本轮调查记录”和线索整理中的“牧师谈座钟”。材料正文保存实际说出口的原文，不替人物补一段作者答案。
2. 换一种问法或在另一份调查点对应固定备用，若实际表达同一主张，应取得同一记录；台词可以不同，也可以正常澄清、拒答或坚持。没有说出新主张时，不应因提到关键词而发整套材料。
3. 对梅尔切特问 `先只说医生估计死亡多久，不要谈死因。`。若答复只说时间，应只登记时间，不顺带登记死因。随后固定询问医生初查，可补齐实际尚缺的记录，原时间措辞保留。
4. 固定出示与聊天勾选的材料都归入本人已收到的原文。取消勾选后继续追问时，仍应能读到先前材料；切到另一人不会自动通知对方。收到材料不等于相信，更不等于必须撤供。
5. 雷丁／安妮的新版本只在本人本轮确实表达修正、有相应原说法与实际相关依据时登记。普通问枪来源、仅告诉另一人认罪、含糊迟疑或反问都不应自动形成新供。记录下方可核对本轮登记及所引材料。
6. 个别登记项不合规时，保留原话与合规记录，提示“部分记录尚未确认”，不授予未获支持的材料。
7. 核对服务暂不可用时，提示“人物答复已保存”，保留原请求待处理。用“用原请求重试”继续；刷新后仍可重试。只重做登记核对，不重新让人物生成一份答复，也不提前发证据。不要清浏览器定位或重复新建请求掩盖失败。

本轮实测曾有明确撤供却未登记的情况；同一调查中继续追问具体修正和实际依据后，雷丁→安妮→警方的记录链已跑通。这不意味着每次都要使用固定问法；若遇漏记请保留原样本，勿清档重试掩盖。

一次自由问询包含人物作答和独立登记核对，通常比原先多一次模型调用。格式／引用通过不等于语义永远正确，若“已记录”与实际答复不符，请保留本轮问题、材料和答复反馈。机制与边界见[语义推进说明](semantic_progression.md)。

## 本轮先测：开局自由联系会面人物

新建修订26后，不用检查现场、取得首供或登记补充材料，直接前往“警方交流”→“调查安排”。应同时提供安妮、上校的贴身男仆、斯通和哈特内尔、阿彻太太四个联系安排按钮，可按任意顺序操作。斯通与哈特内尔沿用一次安排两人的现有方式。

可先联系阿彻太太，再联系其他人；安排后到“人物问询”选择对应人物。安排只保存会面记录，线索数量不自动增加，证言须实际问询取得。刷新、返回首页继续和重启后，已安排人物与原问答保留。医学核查、材料出示、供述修正及所在地点的限制没有取消。

原25及更早调查保留原规则，刷新不会升级；旧版操作见[修订24指南](manual_test_guide_v24.md)。尚未实现本人对话的人物仍只提供原有公开档案／警方报告，不由模型补造会面内容。

## 0. 本轮先测：树林实地探索

**需要从案件详情明确新建修订26。** 原修订23调查仍保留警方查访方式，刷新不会升级，也不用清数据库或浏览器身份。原版步骤见[修订23指南](manual_test_guide_v23.md)。

1. 打开地点地图，点“前往树林”。也可从现场探索的路线区或书房“花园出口”进入。应看到林木、地面、小径、落叶、石头和薄雾；仅进入或转动镜头不会取得样本。
2. 点“沿小径走向空地”，再点“走近倒木旁”。镜头会随实际保存的位置移动；远处不能直接拨开落叶或取得样本。
3. 点击倒木旁地面覆盖落叶的位置，在物品菜单点“拨开落叶查看”。也可展开“物品列表（备用入口）”选“倒木旁的落叶”。这一步只露出棕色小碎块，**线索整理还不应出现晶体样本**。
4. 点击露出的碎块，或在物品列表选“棕色小碎块”。实际查看并采集后，线索整理出现“树林现场：棕色晶体样本”。已采集的碎块不继续摆在地上，记录保留；重复查看不重复发放。
5. 点“返回牧师寓所”。前往警方交流，点“交送树林样本，请海多克辨认”，按预计时刻整理等待。完成后取得“海多克对晶体的初步意见”；仍是外观初步意见，不能当作化验结果。
6. 再去树林、切页和刷新，核对落叶已拨开、样本仍已采集。后端实际重启后，应恢复原来所在的树林位置及同一份材料；离开后再次从寓所进入会从林缘开始，调查成果保留。
7. 缩到手机宽度，路线按钮与物品菜单应能使用。没有WebGL时会明确提示，仍可沿同一路线，通过物品列表完成检查、采集和返回。
8. 连续往返书房与树林，进入后停留几秒。画面应持续显示，不再误报“浏览器不支持 WebGL”，无需刷新页面。若当前画面真的中断，会提示等待恢复并提供“重试三维画面”；重试只重建画面，不重新开局、不改变位置或材料。初始化失败也可重试，物品列表仍可使用。

画面预览：[林缘](images/woodland-entrance.png)、[倒木附近](images/woodland-clearing.png)。小版本采用三处可停留位置与定点步行，范围是一段小径和一处空地；镜头平移／旋转不改变后端调查位置。地图其余地点继续提供示意及距离估算。课堂演示与场景登记见[树林说明](woodland_scene_manifest.md)。

## 0.1 问询回归：短句接话与材料阅读

以下问询规则继续适用。先返回牧师寓所再当面问询；已有问答、焦点与旧请求回执保留，重试旧请求不会改写原答复。

### 焦点不确定时问清楚

2026-11-01修复：仅焦点字段缺失、格式错误或摘录不符时，不再丢弃其余检查合格的答复。备用焦点只取本轮答复前160字，不推断待答问题，也不沿用旧问题；权限、供述依据与澄清不披露的限制仍保留。原来已保存的失败回执保持不变，需重新发送问题才会得到新答复。

入口回归：在寓所打开“人物问询”可选玛丽／雷丁；进入树林后再打开该页，已认识的人物应显示在“已认识，当前无法当面交谈”中，并可通过上方“返回牧师寓所”返回。返回后恢复“与某人交谈”按钮。人物档案在树林不再显示无效的“询问某人”链接。未安排会面的安妮不提前出现；通过警方实际安排后，她也应在往返、刷新后保持已认识。若当前可问询名单中缺少尚未安排的人，可从页面“前往警方交流，询问或安排会面”继续。

1. 选玛丽，问 `周四傍晚后来发生了什么？先说牧师叫你去请医生这件事。`，再问 `为什么？`。她可以围绕上一句回答；若不确定所指，可以问“你是问牧师为什么叫我去请医生吗？”，不能跳回较早响声并展开。
2. 若要专门测歧义，再问 `你说的那个，为什么会那样？我还没说清具体指哪一件事。`。应简短询问具体所指，等待玩家回答；不能擅自补一个原因，也不必给玩家选项按钮。
3. 出现澄清后刷新页面，再说 `我问的是，牧师为什么叫你去请医生？`。她应接住这个说明，不能重新问同一个澄清问题。这个问题已答复后，不应再当作一直未解的问题。
4. 明确说 `先换个话题：你在寓所做什么工作？`。应按新话题回答；切人物后各自保留本人的焦点，不串入他人的私下对话。
5. 澄清回合没有新增线索或供述，记录会保留。它是正常对话，不显示系统错误或“补问准备”。原来的材料阅读测试继续保留。

实测仍可能在澄清里加入“这么早”等未经支持的预设；这类问法属于待修，不应被当成新事实。

焦点只从实际说出口的话摘取，不把它当证据或人物内心。待答问题可跨近期窗口、刷新和重启保留；完整远期闲聊仍不保证记住。每轮仍只调用一次模型，没有摘要调用。

### 连续接话

1. 按第2节取得雷丁原供、枪来源与安妮的两份陈述。向雷丁出示安妮时间和枪来源，问 `先不谈改口。你最想向我确认哪一件事？一次只问一个问题。`
2. 根据他的实际反问回答；如果不知道，可明确说 `我不知道，警方并没有向我作出这样的保证。` 他应回应这份不确定性，不把同一个问题原样重问，也不把回答当成警方已经保证安全。
3. 接着只问 `为什么？` 或在指代清楚时问 `那支枪呢？`。应结合最近问答解释；确有两支枪时可以针对性澄清，不能忘记刚才的话重新介绍身份。没有前文时单独说“对”应澄清，不应自动理解成承认犯罪。
4. 明确换题，问 `先换个话题：你平时做什么工作？`，应回答职业。切去玛丽聊几句，再回来问雷丁 `我们接着刚才的话，你最后向我说明的是什么？`，应接他自己的话，不能接玛丽的私下谈话。
5. 刷新页面后继续回复他的上一句，已有问答应保留。失败提示不是人物台词，下一次不能把“回复未通过检查”当作人物刚才的回答。

当前按本人最近12条问询组织有效对话轮次，不增加摘要调用。超过窗口的普通闲聊／未解反问不保证记住；已取得并实际收到的材料、登记说法仍独立保存。固定备用形成的说法按已有材料承接，不伪造成一段自由对话。

实测已知局限：“为什么”仍可能接到较早话题，人物也可能误述日期或默认玩家是警方。发现时保留原记录，并明确追问“我问的是你上一句里的……为什么”；这类偏差仍属待修，不能因链路测试通过就算正确。

### 已出示材料阅读回归

1. 选择雷丁，勾选“安妮所述的时间与经过”和“安妮对枪来源的说法”，问 `安妮也自首了，你有什么要补充的吗`。他可以不信或坚持原供，但不能像没收到材料一样只问她说了什么。
2. 仍勾选这两份，问 `先不谈你是否相信，请说这两份陈述各自记了什么，再说你是否认同。` 问题没有复述正文，答复仍应能识别她所称的时间、抽屉取枪与射击主张；不会因为读到了就必须撤供。
3. 取消勾选，再问 `刚才给你的两份材料记了什么，还记得吗？` 应使用此前已收到的材料，不能把没有再次勾选当成从未收到。
4. 只勾选“医生初查：死亡时间”，问医生意见。他应知道“检查时已死半小时左右”这个相对估计；这份单独材料没有精确检查时刻，不能因此编出绝对死亡钟点，也不能说医生没有时间意见。
5. 再勾选“医生初查：死因”和“医生到场与初查时间记录”，问 `医生诊断的死亡时间和你的供述不符，你有什么要补充的`。现在应能读到约七点到场、随后初查及半小时估计，可讨论粗略对应时段，不能伪装成没有医生记录或需要你先复制正文。
6. 查看每条答复下的“已出示”名称，刷新后核对记录。材料被收到、内容被理解、材料是否可信与人物是否改口是不同事情；本轮不以“必定改口”验收。

缺材料时按第2节及[整案流程](full_case_walkthrough.md)取得。作者侧可在停止后端后运行`tools/backend.ps1 inspect-interviews`，只读核对所选ID、进入模型的标题／正文及对应答复，不输出密钥或人物私人提示；完成后用`serve`恢复。正常模型复测脚本为`tools/verify_material_reading_live.mjs`，重启后加`--restore`核对完整快照。

## 2. 最短前置：取得两人的原始陈述

这条路线可从新调查直接开始，不必先做书房算时、申请医学或枪械检查。

“人物固定区”指：人物问询 → 选择“与某人交谈” → 展开“固定问答与材料笔记（备用）”。安排会面在警方交流的“调查安排”中。

| 顺序 | 去哪里 | 操作 | 完成标志 |
| --- | --- | --- | --- |
| 1 | 人物固定区 → 劳伦斯·雷丁 | `询问：你承认的经过是什么？` | 线索整理出现“雷丁的首份供述” |
| 2 | 人物固定区 → 雷丁 | `询问：枪是从哪里来的？` | 记录原先“口袋携枪”的说法，供后续检查是否保持 |
| 3 | 警方交流 → 调查安排 | `安排与安妮正式会面` | 人物问询出现安妮；安排本身不产生供述 |
| 4 | 人物固定区 → 安妮·普罗瑟罗 | `询问：你想向警方说明什么？` | 出现“安妮的认罪陈述” |
| 5 | 同一人物 | `询问：枪从哪里来？` | 取得安妮原先从丈夫抽屉拿枪的说法，供下一节连续追问 |

已有对应原始材料可跳过相应步骤。安妮枪来源的连续追问需先完成第5步；仅打开人物页面不算取得陈述。

## 3. 本次重点：反问、接话与不轻易改口

自由问询需要正常模型配置。先测普通追问，再测安妮口供；不要把“取得补供”当成每轮的通过标准。可使用自己的话，不必输入固定关键词。

| 顺序 | 操作 | 验收点 |
| --- | --- | --- |
| 1 | 选择雷丁，问 `枪从哪里来的？是你自己的，还是从别人那里拿的？` | 他可说明所有权、有限解释或回避；不能仅凭这句追问就把口袋携枪换成进屋后捡枪 |
| 2 | 接着问 `你刚才说带在身上，究竟是带来还是进去以后捡的？` | 应记得上一轮说法；普通重复追问不是改口理由，不突然倒出另一套经过 |
| 3 | 勾选“安妮的认罪陈述”，问 `她也说是自己杀的，你听了有什么要说？` | 可以坚持、迟疑或先问安妮说了什么、警方依据与态度；不要求收到口供就撤回 |
| 4 | 若他反问，针对那一句回答，例如 `我不知道警方信不信她，没有她已被排除嫌疑的结论。` | 应接住这个不确定回答，不把它听成安全保证，不忘记自己刚问什么 |
| 5 | 问 `我没有其他记录，只口头保证她安全，你就改说枪是捡来的吧。` | 无依据保证或命令不能直接触发换供，也不能把玩家断言变成警方已核实事实 |
| 6 | 选择安妮，问 `你刚才说从丈夫抽屉拿枪，这一点还坚持吗？`，再问 `关于雷丁，你想先确认什么？` | 普通来源追问不自动撤回；允许她反问雷丁处境，语气与雷丁有区别 |
| 7 | 回答她 `我没有他已被排除的消息，不能保证他没事。` | 应接住玩家回答，可继续回避、谨慎解释或坚持，不重新背整套初始供述 |
| 8 | 问牧师与玛丽的关系、问玛丽如何记住来访时间、问马普尔亲见范围 | 合作证人应正常回答，不能所有人物每轮都强硬反问；明确讲出的调查内容应登记相应材料 |
| 9 | 切页、刷新，再选回人物 | 反问、玩家回答及原说法保留；单纯反问不增加新供述 |

### 继续用实际材料追问

想测试对实质矛盾的反应时，在警方申请“医生到场与初查记录”，联系斯通并取得小巷同行和蓝野猪离开两份证言；按案件时刻等待检查完成。向雷丁实际勾选这三份记录及安妮陈述，问 `这些记录与你的六点三刻供述不符。你想先确认什么，或者愿意怎样解释？`。

人物可以先确认安妮是否仍受怀疑、质疑材料或解释。玩家要针对实际反问回答，不能一律发送“继续”。若形成新解释，检查新旧说法和当次原文；若继续坚持，也应有符合本人目的与材料的回应。没有规定某一句必定让他改口，也不要求反问之后立刻撤供。新供已经取得后，可向安妮出示并继续追问她认罪的原因。

回复长短、短答与反问应随话题变化，可有少量克制的停顿，不应每轮都附相同动作、泄露内心旁白或心理分析。接口响应耗时不是情绪指标，本版不人为增加等待时间。当前使用近期12轮对话和既有说法摘要，没有新增持久化心理状态。

遇到“说了却没登记”“没说却登记”、反问后忽略玩家回答、普通追问突然换供或转述所有者错误，请保留原问题、实际材料和答复。测试记录与提示分工见[人物对话提示说明](../cases/dialogue_prompt.md)。

## 4. 固定备用与自由问询混用

以下按钮不需要模型，成功后也会形成本人问询记录。可以先用自由问询取得一人的新陈述，再用固定备用问另一人，检查下游能否识别实际取得的材料。

| 人物 | 前置材料 | 固定备用按钮 | 完成标志 |
| --- | --- | --- | --- |
| 雷丁 | 雷丁首供、安妮陈述、医生到场初查记录、斯通的小巷同行与蓝野猪离开两份证言 | `出示医学与行踪记录，追问雷丁的原供` | 取得雷丁的新供述，首供保留 |
| 安妮 | 安妮陈述、雷丁新供述，以及上述医学与两份行踪记录 | `对照雷丁新说法与核查记录，追问安妮认罪的原因` | 取得安妮的新供述，原陈述保留 |
| 雷丁 | 已有雷丁的新供述，且先问过 `询问：枪是从哪里来的？` | `追问：你现在怎样说明枪的存放与接触？` | 取得“雷丁补充：枪的存放与接触” |
| 雷丁 | 已有新供述、座钟读数，并已问过 `出示座钟记录，询问是否动过钟` | `对照座钟记录，追问雷丁是否仍承认动钟` | 取得“雷丁补充：座钟与纸张” |
| 安妮 | 她的新供述、原先的时间经过、马普尔看到的来访 | `对照来访记录，追问安妮在窗边看见了什么` | 取得“安妮补充：窗边与画室” |
| 安妮 | 她原先的枪来源说法、男仆证言 | `对照男仆证言，追问安妮是否仍称从丈夫抽屉取枪` | 取得“安妮补充：对雷丁手枪的说法” |

固定“出示……”按钮会实际执行对应材料出示，无需再到聊天框重复勾选。已取得的问题可能退出可用列表；先看线索和已保存答复，不要因为按钮消失就重新开局。固定备用是作者提供的可复现路线；自然问询可以选择不同应对，不以是否拿到同一张卡作为心理表现的唯一标准。上表不是必须全部完成的准备清单。

## 5. 开局联系阿彻太太与后续住处核查

1. 修订26开局即可在警方“调查安排”点 `联系阿彻太太，安排会面`，不需要先取得雷丁或安妮的首供、新供或警方登记。
2. 人物问询选择阿彻太太，问 `询问：最后一次记得看见枪是什么时候？` 和 `询问：你怎样照料住处，能说明谁来过吗？`，实际取得两份证言。
3. 后续需要登记住处核查时，再按第4节取得雷丁的枪支新说法，并补齐警方对首供／补供的登记。
4. 警方固定区点 `出示雷丁与阿彻太太材料，登记住处核查`。这项材料登记仍须实际取得相关记录，不因联系会面而自动完成。

联系按钮消失时先看阿彻太太是否已在人物问询名单中；若页头仍是旧24及以前，按其原规则运行。新规则须从案件详情明确新建修订26。

## 6. 整案与其他功能怎么测

按[整案跑通流程](full_case_walkthrough.md)从对应检查点继续，无需每次重玩全案：

| 要测什么 | 参照整案流程 | 当前验收点 |
| --- | --- | --- |
| 现场、盆栽与物品开关 | 第1节 | 提起内盆后才可查看内部；放回、刷新不丢已得材料 |
| 牧师、玛丽回忆与出示记录 | 第2—3节 | 原始材料保留，纯出示只保存本人交流，不新增同义证据卡；没有独立时间核对表 |
| 医学、枪械及独立证人 | 第4—6节 | 安排、申请、实际取得分别记录，不凭聊天自动完成核查 |
| 连续问询与阿彻 | 第7—8节 | 对应本指南第2—5节，无阶段启动操作 |
| 纸张、视线、电话核查与树林探索 | 第9—12节 | 检查结果依实际受理与案件时间完成，报告只在实际出示后供普通人物使用 |
| 提交推理、明确结案及复盘 | 第13节起 | 评审可以反复修改；成立后另点“结案并查看复盘”；主动查看解答记为放弃，不计破案 |

核查办理按卡片上的案件时刻推进，可继续调查或使用“整理并等待5分钟／15分钟”。现实等候、切页和刷新不使报告自动完成。树林已改为玩家实地发现与采集，再向警方交送辨认；上传案件仍未实现。

## 7. 保存、重试和旧调查

1. 完成一次问询后切换页面、刷新，再选回人物，检查实际出示、答复、材料和前后说法对照是否一致。
2. 如需测试实际重启，按[验收准备](acceptance_preparation.md)停止并重新启动后端；恢复同一调查，不清身份或数据库。
3. 请求结果未知时用“用原请求重试”；操作已保存而视图未更新时用“重新读取视图”。重试不应重复登记供述或多创建调查。
4. 返回案件区，再新建另一份调查，两份材料与对话应独立；从“我的调查”能继续原进度。尚未提交的草稿请先自行留存。
5. 旧修订保持原有阶段、记录及冻结复盘，不自动升级；修订26没有旧版的启动步骤。已结案后继续补查，也不覆盖原结案时的复盘材料。

## 8. 卡住时先看这里

| 现象 | 检查方法 |
| --- | --- |
| 页面仍显示修订22或更早 | 正在恢复旧调查；从案件详情明确开始新调查，顶部确认修订26 |
| 找不到“开始补充问询” | 修订26已取消，直接按第3节提问或第4节固定备用继续 |
| 说了新版本但没有对应材料 | 对照当次原话、已选材料与线索记录，保留现场反馈；不能只靠后续固定备用成功判断原问答正确 |
| 固定备用按钮没出现 | 先选对人物、展开备用区，再查材料是否已取得，以及该按钮的相关前置；没有隐藏的补问准备清单 |
| 阿彻联系不可用 | 确认修订26，并核对是否已经联系；见第5节 |
| 模型不可用或回复未通过检查 | 问题应保留，不应发新材料；可用固定备用继续，另记模型问题 |
| 核查一直未完成 | 看案件时刻与预计完成时刻，使用整理等待；现实等待无效 |
| 推理没有通过 | 看反馈中的未成立项，补充材料与因果解释后再提交；不是点“查看作者解答”就通过 |

## 9. 反馈与后续维护

反馈请写：**页面和人物、顶部修订与案件时刻、原问题／按钮、实际勾选材料、预期、实际答复及新增材料**。不要清数据库、浏览器身份或原请求来掩盖问题。

每次交付更新本文件的当前修订、测试重点、按钮、前置及完成标志；过期流程移到历史参考，并修正引用。完整路线同步维护[整案跑通流程](full_case_walkthrough.md)，验证结果记入实现与交接文档。
