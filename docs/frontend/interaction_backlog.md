# 已确认的场景交互待办

当前先接通前后端调查闭环，以下需求随后实现，不要求先提高建模精度。

| 需求 | 实现边界 | 验收要点 |
|---|---|---|
| 可逆现场操作，例如推回抽屉 | 现场状态与已获知识分开；由后端验证并保存可逆状态 | 关闭后已获线索不丢失，再打开不重复授予 |
| 切换视野中心 | 镜头关注对象与人物真实地点分开 | 能围绕不同对象观察，不始终绕书桌旋转 |
| 观察普通物体，例如台灯、窗户 | 可观察物体不要求关联线索，普通描述与线索结果分开 | 可选中并查看一般说明；未设定不能解释成确认无异常 |

内容来自用户对首版前端的验收反馈。本次联网切片不把上述交互伪装成已实现。
