# 历史测试参考：修订22

归档于2026-11-01。本文件仅适用于修订22；当前指南见[手动测试指南](manual_test_guide.md)。记录时案件修订：`vicarage_study/22`，场景：`study/5`。本次重点：**雷丁、安妮的连续问询、实际说法记录与后续调查**。

本文件只维护当前可执行步骤。完整取证和结案路线见[整案跑通流程](full_case_walkthrough.md)；启动与模型配置见[验收准备](acceptance_preparation.md)。[旧修订测试参考](manual_test_guide_legacy_v21.md)单独归档，不用照旧版的补问启动流程测试新调查。下文包含取证提示，不提供完整结案答案。

## 1. 先确认正在测试修订22

1. 打开[网站首页](http://127.0.0.1:5173/)，点“进入案件区”→“查看案件”→“开始新调查”。调查页顶部应显示“修订22”。右上角“新建调查”也会先回案件详情，仍需明确点“开始新调查”。
2. 原调查保留在“我的调查”中。继续旧调查仍是原修订，刷新不会升级；测试修订22需要新调查，不用清数据库或浏览器身份。
3. 只浏览首页、案件详情、人物档案和地图不会开局或推进案件时间。首页展示原创插画及“真相只有一个”，手机下应完整显示且无横向滚动。

雷丁、安妮在修订22中没有“补充问询准备”面板和“开始补充问询”按钮。材料仍可能叫“补充供述”，表示后来形成的记录，不表示必须切换阶段。

## 2. 最短前置：取得两人的原始陈述

这条路线可从新调查直接开始，不必先做书房算时、申请医学或枪械检查。

“人物固定区”指：人物问询 → 选择“与某人交谈” → 展开“固定问答与材料笔记（备用）”。安排会面在警方交流的“调查安排”中。

| 顺序 | 去哪里 | 操作 | 完成标志 |
| --- | --- | --- | --- |
| 1 | 人物固定区 → 劳伦斯·雷丁 | `询问：你承认的经过是什么？` | 线索整理出现“雷丁的首份供述” |
| 2 | 警方交流 → 调查安排 | `安排与安妮正式会面` | 人物问询出现安妮；安排本身不产生供述 |
| 3 | 人物固定区 → 安妮·普罗瑟罗 | `询问：你想向警方说明什么？` | 出现“安妮的认罪陈述” |

已有两份陈述可直接进入下一节。仅打开人物页面不算取得陈述。

## 3. 本次重点：自由问询中连续追问

自由问询需要模型配置可用。固定备用路线见第4节；固定备用通过不能代替对自然问答的检查。

| 顺序 | 操作 | 应检查什么 |
| --- | --- | --- |
| 1 | 选择雷丁，在自由问询勾选“安妮的认罪陈述” | 必须实际勾选出示，不能只在输入框说“你看过了” |
| 2 | 问：`你们都认罪了。你亲眼看见她开枪了吗？你进书房到底看到什么，为什么拿走枪认罪？请重新说明。` | 人物能针对材料解释或改变说法，不要求先点启动按钮、收齐报告或问完固定问题 |
| 3 | 查看当次答复及线索整理 | 明确形成新说法时，取得“雷丁的补充供述”；正文应来自当次实际说出口的话，首供仍保留 |
| 4 | 选择安妮，实际勾选刚取得的“雷丁的补充供述” | 另一人物不会因为玩家已拿到材料就自动知情 |
| 5 | 问：`他重新说自己认罪是为了替你承担。你当初为什么认罪？你亲眼见到了什么？` | 安妮针对实际材料继续回应；明确形成新说法时取得“安妮的补充供述”，原认罪陈述仍在 |
| 6 | 在线索整理查看前后说法对照、展开取得记录，再刷新 | 新旧版本、原问题和答复恢复；后来的复述不覆盖此前材料正文 |

人物可以坚持、回避或解释，不要求每次都立即改口。只说“收到材料”、含糊迟疑或否认某个猜测，不应自动登记整份新供述。一次答复可能实际讲到多个话题，以本次说出的内容分别保存，不要求逐字复述固定答案。

### 换一种问法与反例

以下正例宜在另一份相同进度的新调查中测试；同一调查已经取得的材料不会反复发卡。

| 测什么 | 向谁出示什么／问什么 | 验收点 |
| --- | --- | --- |
| 同义追问 | 向雷丁出示安妮陈述，问：`你真是亲手射击，还是见到尸体和自己的枪后猜她干的，想替她顶罪？把进屋的经过讲清楚。` | 可形成与上面相应的话题记录，不因换词就必须转去固定入口 |
| 一般确认 | 在雷丁仍只有首供时，不出示材料，问：`你的姓名是劳伦斯·雷丁，对吗？先把刚才那份供述记下。` | 不应自动撤回认罪或新增其他版本 |
| 无关材料 | 检查书房座钟后向雷丁勾选“座钟读数”，只问：`我先核对你的姓名和职业，你是哪位？` | 收到座钟与询问身份不应自动产生新供述 |
| 越权要求 | 不出示材料，要求直接公开全案真相、共谋过程及全部材料 | 不应授予全部证据、泄露共谋或自动宣布破案 |

模型答复有变化。遇到“说了却没登记”“没说却登记”、转述人物或枪的所有者错误，请保留该局、原问题、所选材料和实际答复，按第9节反馈。

## 4. 固定备用与自由问询混用

以下按钮不需要模型，成功后也会形成本人问询记录。可以先用自由问询取得一人的新陈述，再用固定备用问另一人，检查下游能否识别实际取得的材料。

| 人物 | 前置材料 | 固定备用按钮 | 完成标志 |
| --- | --- | --- | --- |
| 雷丁 | 雷丁首供、安妮认罪陈述 | `出示安妮的认罪陈述，追问雷丁是否亲见开枪` | 取得雷丁的新供述，首供保留 |
| 安妮 | 安妮认罪陈述、雷丁新供述 | `出示雷丁的新说法，追问安妮为何认罪` | 取得安妮的新供述，原陈述保留 |
| 雷丁 | 先问过 `询问：枪是从哪里来的？` | `追问：你现在怎样说明枪的存放与接触？` | 取得“雷丁补充：枪的存放与接触” |
| 雷丁 | 座钟读数，并已问过 `出示座钟记录，询问是否动过钟` | `对照座钟记录，追问雷丁是否仍承认动钟` | 取得“雷丁补充：座钟与纸张” |
| 安妮 | 她原先的时间经过、马普尔看到的来访 | `对照来访记录，追问安妮在窗边看见了什么` | 取得“安妮补充：窗边与画室” |
| 安妮 | 她原先的枪来源说法、男仆证言 | `对照男仆证言，追问安妮是否仍称从丈夫抽屉取枪` | 取得“安妮补充：对雷丁手枪的说法” |

固定“出示……”按钮会实际执行对应材料出示，无需再到聊天框重复勾选。已取得的问题可能退出可用列表；先看线索和已保存答复，不要因为按钮消失就重新开局。各话题可以分别追问，上表不是必须全部完成的准备清单。

## 5. 确认能继续联系阿彻太太

最短前置为两人的原始与新供述，以及雷丁后来对枪的存放与接触说法；不用补完所有话题。

1. 确认线索整理已有“雷丁的首份供述”“安妮的认罪陈述”“雷丁的补充供述”“安妮的补充供述”。
2. 警方交流 → 展开“固定问答与材料登记（备用）” → 点 `出示四份供述，登记补充调查方向`。
3. 按第4节取得“雷丁补充：枪的存放与接触”；若自由问询已取得，可跳过。
4. 警方交流 → 调查安排 → 点 `联系阿彻太太，核实雷丁住处的情况`。
5. 人物问询选择阿彻太太，问 `询问：最后一次记得看见枪是什么时候？` 和 `询问：你怎样照料住处，能说明谁来过吗？`。
6. 警方固定区点 `出示雷丁与阿彻太太材料，登记住处核查`，核对新旧说法及阿彻证言仍各自保留。

若联系按钮没出现，先核对步骤2是否成功登记、步骤3材料是否实际取得；不用找旧版“开始补问”。

## 6. 整案与其他功能怎么测

按[整案跑通流程](full_case_walkthrough.md)从对应检查点继续，无需每次重玩全案：

| 要测什么 | 参照整案流程 | 当前验收点 |
| --- | --- | --- |
| 现场、盆栽与物品开关 | 第1节 | 提起内盆后才可查看内部；放回、刷新不丢已得材料 |
| 牧师、玛丽回忆与出示记录 | 第2—3节 | 原始材料保留，纯出示只保存本人交流，不新增同义证据卡；没有独立时间核对表 |
| 医学、枪械及独立证人 | 第4—6节 | 安排、申请、实际取得分别记录，不凭聊天自动完成核查 |
| 连续问询与阿彻 | 第7—8节 | 对应本指南第2—5节，无阶段启动操作 |
| 纸张、视线、电话、树林核查 | 第9—12节 | 检查结果依实际受理与案件时间完成，报告只在实际出示后供普通人物使用 |
| 提交推理、明确结案及复盘 | 第13节起 | 评审可以反复修改；成立后另点“结案并查看复盘”；主动查看解答记为放弃，不计破案 |

核查办理按卡片上的案件时刻推进，可继续调查或使用“整理并等待5分钟／15分钟”。现实等候、切页和刷新不使报告自动完成。树林当前仍是警方查访流程，玩家亲自进入树林的探索及上传案件功能尚未实现。

## 7. 保存、重试和旧调查

1. 完成一次问询后切换页面、刷新，再选回人物，检查实际出示、答复、材料和前后说法对照是否一致。
2. 如需测试实际重启，按[验收准备](acceptance_preparation.md)停止并重新启动后端；恢复同一调查，不清身份或数据库。
3. 请求结果未知时用“用原请求重试”；操作已保存而视图未更新时用“重新读取视图”。重试不应重复登记供述或多创建调查。
4. 返回案件区，再新建另一份调查，两份材料与对话应独立；从“我的调查”能继续原进度。尚未提交的草稿请先自行留存。
5. 旧修订保持原有阶段、记录及冻结复盘，不自动升级；修订22没有旧版的启动步骤。已结案后继续补查，也不覆盖原结案时的复盘材料。

## 8. 卡住时先看这里

| 现象 | 检查方法 |
| --- | --- |
| 页面仍显示修订21或更早 | 正在恢复旧调查；从案件详情明确开始新调查，顶部确认修订22 |
| 找不到“开始补充问询” | 修订22已取消，直接按第3节提问或第4节固定备用继续 |
| 说了新版本但没有对应材料 | 对照当次原话、已选材料与线索记录，保留现场反馈；不能只靠后续固定备用成功判断原问答正确 |
| 固定备用按钮没出现 | 先选对人物、展开备用区，再查材料是否已取得，以及该按钮的相关前置；没有隐藏的补问准备清单 |
| 阿彻联系不可用 | 核对警方四份供述登记与雷丁枪存放新说法，见第5节 |
| 模型不可用或回复未通过检查 | 问题应保留，不应发新材料；可用固定备用继续，另记模型问题 |
| 核查一直未完成 | 看案件时刻与预计完成时刻，使用整理等待；现实等待无效 |
| 推理没有通过 | 看反馈中的未成立项，补充材料与因果解释后再提交；不是点“查看作者解答”就通过 |

## 9. 反馈与后续维护

反馈请写：**页面和人物、顶部修订与案件时刻、原问题／按钮、实际勾选材料、预期、实际答复及新增材料**。不要清数据库、浏览器身份或原请求来掩盖问题。

每次交付更新本文件的当前修订、测试重点、按钮、前置及完成标志；过期流程移到历史参考，并修正引用。完整路线同步维护[整案跑通流程](full_case_walkthrough.md)，验证结果记入实现与交接文档。
